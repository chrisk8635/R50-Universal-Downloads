# KG2L Universal R50 Connector v1.0 RC1

**Free early community test build for Windows (64-bit).**

### What works
- Garmin Approach R50 shot data relayed through a properly installed GSPconnect.exe.
- Muni Golf using its OpenConnect interface.
- PurePlay Golf using its OpenConnect JSON interface.
- Automatic club selection, including automatic switching into putting mode.
- Full shots, short-game shots, and putting.
- Connector shutdown followed by normal GSPro gameplay.

### Initial field results
- PurePlay: **two holes completed successfully**, including putting.
- Muni: **passed a live universal-connector test**.
- GSPro: **three holes played normally after shutting down the connector**.

### Installation prerequisites
- **Windows 10/11, x64** PC.
- **Garmin Approach R50** (not R10).
- Existing, authorized installation of **GSPconnect.exe** from GSPro (not supplied).
- **Muni Golf or PurePlay Golf** installed on the same Windows PC, with OpenConnect enabled.
- Connected R50 and PC network. **GSPro game closed while using this connector.**
